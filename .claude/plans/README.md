# Plans

This folder holds saved implementation plans for non-trivial features or refactors in this project.

## Convention

- One file per plan: `YYYY-MM-DD-short-slug.md` (e.g. `2026-09-16-add-department-endpoint.md`).
- A plan should cover: the goal, the files/layers it touches (controller/dto/entity/service/repository/mapper —
  see [[structure]]), and any new rules or endpoints that need corresponding updates to `.claude/rules/` or
  `.claude/api.md` once implemented.
- Once a plan is fully implemented, either delete it or mark the top of the file `STATUS: done` — don't let
  stale in-progress plans accumulate.
